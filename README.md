One image that sums up the world news of **Wednesday 25 November 2026**, entered in the
[make.fun bounty "Sum up 25 November's world news in one image"](https://make.fun/bounty/news-image-20261125).

The image is a newspaper front page — masthead, a UTC timeline strip, and 16 stories
in a grid, each with its own drawn scene, a headline, a CLAIM/CONFIRMED tag, and the
source printed directly underneath. Every story was verified against a credible
report dated 25 November 2026 (Reuters, BBC, AP, ESA, EarthSky).

## How it works

`main.py` (Python 3.13, standard library only) copies `entry.png` byte for byte
to `$MAKEFUN_OUTPUT_DIR/entry.png` and checks the copy landed at the same size.
No network, no randomness, no timestamps — both runs write identical bytes.

## Run it locally

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Then open `out/entry.png` — a 1024x1024 PNG, under 1 MiB.
